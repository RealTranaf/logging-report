**Logging ở frontend (ReactJS)**

Log ở frontend thường sẽ đi tới console của trình duyệt, một dịch vụ logging của bên thứ 3 hoặc vào một API nhận log riêng ở phía backend.

1. Logging ra console: JavaScript có hỗ trợ nhiều mức logging như console.log, console.error, console.warn... VD:

```
const openEditModal = async (id) => {
    const game = await getGameById(id)
    setSelectedGame(game.data)
    setModalMode("edit")
    setModalOpen(true)
    console.log("Edit modal opened.")
}
```

Có thể setup một function logging riêng như:

```
const logger = {
  info: (msg) => console.info("[INFO]", msg),
  warn: (msg) => console.warn("[WARN]", msg),
  error: (msg) => console.error("[ERROR]", msg)
};

export default logger;
```

và khi cần log chỉ cần gọi function này:

```
import logger from "./logger";

logger.info("Game list loaded");
logger.error("API request failed");
```

2. Gửi log về phía backend: Frontend React có thể gửi log về phía backend thông qua API, từ đó backend sẽ ghi lại log vào một file. Như thế, log của frontend và backend sẽ cùng nằm trong backend, tăng tính thống nhất. Tuy nhiên sẽ thực hiện nhiều request HTTP và làm chậm hệ thống. 

3. Gửi log về một dịch vụ logging bên thứ 3 (do tính chất đề tài lần này, ko tìm hiểu phần này)

=> Triển khai phương án thứ 2: có thể lưu trữ được log, thống nhất chứa log tại cùng một nơi, có thể sử dụng thư viện Logback của Spring ở backend để configure log frontend.
