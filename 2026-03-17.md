**Ollama**

Ollama là một runtime local chạy các model LLM mã nguồn mở trực tiếp trên máy người dùng hay trên cloud server của Ollama. Ollama có thể chạy model dể người dùng nhanh chóng nhắn tin cùng hay chạy các công cụ AI như Claude Code, Codex, OpenClaw, n8n.

Ollama cung cấp và hỗ trợ cả model local chạy trên máy người dùng lẫn cloud model chạy trên dịch vụ cloud của Ollama. Để sử dụng cloud modal cần tạo một tài khoản Ollama.

Để bắt đầu, cần thực hiện tải Ollama về hệ thống:

```
curl -fsSL https://ollama.com/install.sh | sh
```

Nếu muốn sử dụng model local, thực hiện pull model về:

```
ollama pull glm-4.7-flash
# hoặc
ollama pull gpt-oss:20b
# hoặc
ollama pull llama3.3
```

hoặc nếu sử dụng model cloud, thực hiện đăng nhập vào tài khoản Ollama:

```
ollama signin
```

**Sử dụng Ollama để chạy OpenClaw**

**Cách 1** Nếu chưa cài đặt OpenClaw, có thể launch trực tiếp qua Ollama sử dụng lệnh:

```
ollama launch openclaw
```

Ollama sẽ tự động cài đặt và config bảo mật, model, chọn provider, cài đặt và khởi động gateway.

Có thể chạy ollama launch openclaw --config để config manual cho OpenClaw hoặc ollama launch openclaw --model kimi-k2.5:cloud (VD) để chọn model cụ thể.

Note: Ollama khuyên dùng model cloud kimi-k2.5:cloud, minimax-m2.5:cloud, glm-5:cloud hoặc model local glm-4.7-flash.

Nên thực hiện cách này nếu hệ thống chưa cài đặt và setup OpenClaw.

**Cách 2** Chọn Ollama làm model provider trong onboarding wizard của OpenClaw.

Note: cần update OpenClaw để có thể chọn Ollama làm provider.

Để chọn, chạy openclaw onboard để mở onboarding wizard. Khi tới phần provider, chọn Ollama. Chọn một model cloud hay local, xác thực tài khoản Ollama nếu cần và hoàn thiện setup. Bây giờ OpenClaw sẽ sử dụng model mới do Ollama cung cấp để chạy.

Nên thực hiện cách này nếu hệ thống đã setup OpenClaw từ trước và muốn đổi model provider.

Note: cần tải Ollama về máy trước để sử dụng provider này.

Để chạy model local, cần hệ thống có GPU khỏe, nhiều VRAM.
